# NUVION — Атомдық & Ядролық Физика

Мобильное учебное веб-приложение по атомной и ядерной физике (KK / RU / EN).

**Экраны:** главная · темы · тесты (5 вопросов на тему) · практические задачи (3 на тему, с подсказками) · профиль с XP, уровнями, графиком и статистикой · достижения · AR-лаборатория (3D-атом, вращение пальцем, выбор элемента) · библиотека · карта обучения.

Чистый HTML/CSS/JS без сборки, прогресс хранится в `localStorage`.

## Открыть по ссылке (GitHub Pages)
Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)` → Save.
Адрес: `https://ekuai1952.github.io/NUVION/`

## Структура
- `index.html` — точка входа
- `style.css` — стили
- `data.js` — контент (тексты интерфейса, темы, вопросы, задачи) на трёх языках
- `app.js` — логика экранов
